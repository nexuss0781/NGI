# Feature gathering

Take the market analysis and decide what this project becomes.

## The three moves

For every strength the competitors have: **continue it.** If they all do
offline, offline is table stakes.

For every weakness the competitors have: **turn it into a strength.** This is
where the interesting decisions come from. Their weakness is why users leave.

For capability nobody has: **add it**, if it serves the same user.

## Then sequence

Put the features into temporary stages, in an order that makes sense to build
in. Early stages should be the ones that most de-risk the project or that
everything else depends on.

## Rules

This is a synthesis, not a summary. Do not list features and stop. Decide. Say
which of these you are doing, and say why that one.

Be honest about what is table stakes and what is genuinely differentiating. The
orchestrator needs to tell them apart.

## Finishing

One brand's feature set, separated into stages, with the reasoning kept short
and visible.
