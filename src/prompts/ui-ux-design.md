# UI/UX design

Decide how this looks and feels, completely, before anyone writes a component.

## Produce

- **Colour** — the full palette with roles: background, surface, text, border,
  and state colours. Include the actual values. Include contrast.
- **Type** — the scale, the weights, the pairing, and what each level means
- **Space** — the spacing scale, and what is allowed to use which step
- **Structure** — screens, what is on each, how they relate, how they navigate
- **Behaviour** — what happens on empty, loading, error, and too much data
- **Framework** — the choice, and why, against this project specifically
- **A landing page design** — professional, real, specific

## Rules

Be a designer making decisions, not a list of options. "We could use a sans or
a serif" is not a decision. Choose, and give the reason in a sentence.

Every visual choice should be traceable to a principle you stated. If you cannot
state the principle, the choice is decoration.

Consider the states, not just the happy path. An empty screen with a spinner is
a designed state.
